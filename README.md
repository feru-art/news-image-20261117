One image that sums up the world's news of Tuesday 17 November 2026, as a
magazine cover: the Kerch Bridge hit again (hero photo), mines near Hormuz,
the Xi–Trump–Putin summit announced for 19 November, and jets scrambled —
under the masthead "THE WORLD" and the date "17 NOVEMBER 2026".

Entry for the make.fun bounty [news-image-20261117](https://make.fun/bounty/news-image-20261117).
The image was made with Generate Image via Milku; `main.py` only copies its
finished bytes to the output.

## Run

```sh
python3 main.py
```

Writes the image to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`
when that variable is set). Deterministic: two runs write identical bytes.

## Files

- `main.py` — the entry program (Python 3.13, standard library only)
- `image.jpg` — the bundled image (JPEG, 1024×1024, 208,136 bytes)
