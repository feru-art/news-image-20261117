Entry for the make.fun bounty [Sum up 17 November's world news in one image](https://make.fun/bounty/news-image-20261117): a front page summing up Tuesday 17 November 2026 — hero photo of the burning Kerch Bridge, a map label strip, six headline cards with icons, and an 18-story list. The image was made with Generate Image; the program only copies it to the output.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (a JPEG, told apart by its first bytes, as the rules allow). Set `MAKEFUN_OUTPUT_DIR` to change the output directory. Deterministic: two runs write identical bytes. No network.
