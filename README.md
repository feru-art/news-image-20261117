One image that sums up the world's news of Tuesday 17 November 2026, as a
newspaper front page: the Kerch Bridge hit again, mines near Hormuz, the
Xi–Trump–Putin summit announced for 19 November, jets scrambled over Japan,
and the Gaza aid call. The image was made with Milku's Generate Image; the
program only validates it and copies its bytes to the output.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` — a JPEG (1024×1024, under 1 MiB), which the rules
allow at that path: the file is told apart by its first bytes, not its name.
Two runs write the same bytes; no network.
